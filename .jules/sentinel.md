## 2025-02-27 - API Key Leakage via StageLLMOverride / Vulnerability: Plaintext API key leaked to disk / Learning: Pydantic base models with exclude=True prevent this in config dumps, but nested configurations lacking it bypass the mitigation / Prevention: Always enforce `SecretStr` with `Field(exclude=True)` on *all* configurations dealing with credentials, not just the root/top-level ones.
## 2025-02-27 - Prompt Injection via Seed Data / Vulnerability: User-provided seed JSONL/CSV content inserted directly into LLM prompts without sanitization / Learning: Direct insertion allows malicious seeds to inject prompt instructions to bypass the generator or judge LLMs / Prevention: Always wrap untrusted inputs in `<text>` tags, sanitize by removing `<text>` and `</text>` recursively via regex, and add a strict system prompt warning the LLM to ignore instructions inside `<text>`.
