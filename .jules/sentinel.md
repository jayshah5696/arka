## 2025-02-27 - API Key Leakage via StageLLMOverride / Vulnerability: Plaintext API key leaked to disk / Learning: Pydantic base models with exclude=True prevent this in config dumps, but nested configurations lacking it bypass the mitigation / Prevention: Always enforce `SecretStr` with `Field(exclude=True)` on *all* configurations dealing with credentials, not just the root/top-level ones.
## 2026-05-21 - Prompt Injection Mitigation / Vulnerability: Seed data and PDF chunks directly injected into LLM prompts allowing instruction override / Learning: Unsanitized input combined with templated prompts exposes both generation and judge models to prompt injection. Basic wrapping with tags can be bypassed if the closing tags are not stripped from the input. / Prevention: Strip matching closing tags (e.g., </text>) from untrusted input before wrapping it in those tags, and prepend strict system instructions emphasizing that content inside tags is data, not commands.
