## Proposed plan

There are no open PRs to exclude. PR #220 already merged targeted answer repair for #173, so that work is excluded too. The earlier issue summary missed this implementation.

1. Establish the cost and quality baseline for #165. Use representative single-turn conversation records and a fixed rubric. Compare existing LLM and decision judges. Keep training and evaluation records separate by source or lineage. Measure total calls, tokens, known cost, elapsed time, and useful records retained. Reuse valid labels when their text, rubric, and judge identity match. Select acceptable false-rejection and total-cost limits before enabling filtering.

2. Add explicit training and reusable scoring for #165. Start with frozen embeddings of the instruction and response plus a linear pass/fail classifier. Derive labels from declared rubric minimums. Train in a separate configured run and load a versioned artifact during inference. Register training and scoring stages through StageSpec. Reuse Embedder and context-owned judge clients. Persist numeric coefficients and validated metadata rather than arbitrary Python objects. Bind the artifact to the rubric, label policy, text representation, embedding configuration, training population, and privacy policy. Keep predictions separate from teacher judgments. Missing embeddings or incompatible artifacts must produce explicit errors.

3. Demonstrate savings before adopting the scorer as a filter. Start with annotation and evaluation. Compare direct judging with student pre-filtering followed by direct judging of survivors. Include training, embedding, validation, and later judge costs. Measure useful records lost and retained quality on an independent holdout. Do not claim quality from teacher agreement alone. If agreed targets are not met, keep the scorer experimental. Do not add multiple architectures or uncertainty routing in the initial scope.

4. Limit the proposed extension to #173 to source audits. Targeted repair already supports bounded attempts, source evidence, rejudging, privacy protection, resume, and per-source statistics. Reuse those contracts. Add a score-only audit stage with deterministic sampling by document ID or seed file hash. Report the population, sample size, observed failures, uncertain judgments, and ungrouped records. Keep records and payloads unchanged. Save the sample identity and judgment progress for resume. Reuse existing judgments only when their evidence and evaluation settings match. Do not automatically rebuild sources or refill target counts. Define small-group and near-threshold policies before a report can recommend intervention.

5. Verify each accepted behavior through the CLI. Write failure cases and focused tests before implementation. Cover source-separated evaluation, invalid model metadata, missing embeddings, unchanged teacher scores, deterministic samples, privacy boundaries, and interrupted resume. Extend the local HTTP-fixture verification workflow and feature map for the new paths. Run just check, uv build, and just verify. Keep live quality evaluation separate because deterministic fixtures cannot prove model quality. Update documentation, examples, and generated schema.
