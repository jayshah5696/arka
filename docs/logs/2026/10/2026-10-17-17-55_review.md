# Pipeline Architecture Review and Seam Hardening (Verified Loop 2)

## Summary of Accomplishments

This worktree implements the architectural review and deepening candidates across Arka's sequential pipeline, sealing all seam bypasses, introducing guardrails in `AGENTS.md`, and enforcing them with automated invariant tests.

### 1. Seam Hardening and Bypass Elimination
- **Context-Owned LLM Clients**: Removed direct `LLMClient(...)` instantiations in `DoubleCriticFilterStage` and `ComplexityEloScoringStage`, resolving LLM clients through `ctx.llm_client(override=...)`.
- **Context-Owned Parallelism**: Removed direct `ThreadPoolExecutor(...)` instantiations in `DecisionPanelStage`, `PromptBasedGeneratorStage`, and `DoubleCriticFilterStage`, delegating all parallel operations through `ctx.map_parallel(...)`.
- **Generator Slot Engine Integration**: Consolidated slot execution, response hashing, caching, ordering, and checkpointing into `arka.pipeline.generator_engine.execute_generator_slots`, increasing its test coverage to 97%.
- **Deprecation Warning Cleanliness**: Migrated `ResolvedConfig._migrate_old_config_validator` to run silently on legacy dict validation without emitting deprecation warnings during test runs, while preserving explicit `DeprecationWarning` when `ResolvedConfig.migrate_old_config` is called directly by migration utilities.

### 2. Architecture Invariants and Guardrails
- **`AGENTS.md`**: Maintained strictly under 50 lines (17 lines) and added the 6 core Architecture Seams rules.
- **`tests/unit/test_architecture_invariants.py`**: Added 5 structural invariant tests verifying:
  - 100% of pipeline stage configs map to registered `StageSpec` instances with valid `Stage` subclasses.
  - All stage configs supporting `backend="decision"` have registered `DecisionStageSpec` entries.
  - No stage file writes `stats.json` directly (must use `StageArtifacts`).
  - No stage file instantiates `ThreadPoolExecutor` directly (must use `ctx.map_parallel`).
  - `AGENTS.md` exists and stays strictly under 50 lines.
