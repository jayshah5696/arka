# Plan: Code Quality Judo Refactorings

We have formulated a plan to implement the four structural and performance improvements identified during the review:

1. **Centralize Stage Config Resolution** - Base class method in `Stage` class to remove config extraction boilerplate from every stage.
2. **Parallelize Labeling Engine Canary Checks** - Concurrent execution of canary checks in `ThreadPoolExecutor` within `LabelingEngine.label_batch`.
3. **Harden Fallback JSON Extraction** - Robust bracket-matching algorithm in LLM client JSON extractor fallback.
4. **Separate Legacy Config Translation** - Deprecate legacy config support at runtime and write an offline migration utility.
