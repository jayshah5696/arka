# Check and Plan: Migrate argparse to click

We analyzed the codebase and found the usage of `argparse` in the following files:
1. `src/arka/cli.py` - The main CLI wrapper for running pipelines.
2. `scripts/migrate_config.py` - Script for migrating legacy configurations to the modern format.
3. `tools/simula_eval/compare.py` - Utility for comparing metric slices side-by-side.
4. `tools/simula_eval/metrics.py` - Harness for computing comparison metrics on run output.

## Proposed Strategy

1. **Add Dependency**: Add `click` to the project's dependencies in `pyproject.toml` (using `rtk uv add click`).
2. **Main CLI (`src/arka/cli.py`)**:
   - Refactor `build_parser` and `main` using Click command and options decorators (`@click.command`, `@click.option`).
   - Retain backward compatibility for programmatic invocations of `main(argv)` inside unit tests by invoking `cli.main(args=argv, standalone_mode=False)` and handling standard exit codes without calling `sys.exit` on success.
3. **Migration and Eval Tools (`scripts/migrate_config.py`, `tools/simula_eval/compare.py`, `tools/simula_eval/metrics.py`)**:
   - Replace standard `argparse.ArgumentParser` with Click decorators.
   - Utilize Click's validation and type coercion features, such as `click.Path(path_type=Path)`, to ensure clean type safety.
4. **Verification**:
   - Run existing unit tests via `rtk just check` to ensure correctness and compatibility.
   - Manually run help and dry-run commands.
