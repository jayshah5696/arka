# CLI Validation Audit Log - 2026-05-30

## Goal
Perform a deep code quality audit of the recent configuration validation and stage listing changes in `arka`.

## Initial Findings
1. **Stage Instantiation Validation Bypass**: If `--validate-config` is provided, it only checks YAML schema validation using `ConfigLoader().load(config_path)`. It does not check if the individual pipeline stages can be built successfully via `StageBuilder().build()`, which could hide issues such as unknown stage type strings or invalid/unsupported parameters checked in `from_config()`.
2. **Output Discrepancy**: `--list-stages` is a direct alias for `--dry-run`, but the output printed on `--list-stages` still says `"Dry run enabled. Loaded config: ..."`.
3. **CLI Modularization**: The `cli` function has multiple responsibilities mixed together. Restructuring it will improve legibility.

## Actions Taken
Created the implementation plan in `implementation_plan.md` to outline changes:
- Perform `StageBuilder.build()` validation in `--validate-config`.
- Adjust stdout messages for listing vs. dry running.
- Restructure the CLI method using clean helper components.
