## Findings & Recommendations

### PR 83: Bolt: Cache HuggingFace fastembed TextEmbedding model
* **Branch**: `bolt-fastembed-cache-13258415459098314310`
* **Details**: Adds a global thread-safe cache (`_hf_client_cache` and `_hf_cache_lock`) for the HuggingFace `TextEmbedding` model in `src/arka/embeddings/embedder.py`.
* **Rationale**: TextEmbedding initialization was being executed on every batch, reloading heavy ONNX weights from disk into memory. Caching it avoids this overhead.
* **Recommendation**: **MERGE**. This is a clean performance boost. We will sanitize it by discarding changes to `uv.lock` and `test_config_loader.py` (whitespace slop).
